# Qt Preview

This preview starts the first PySide6-based desktop shell while the existing Tk application remains the default.

Run it from the repository root:

```powershell
py -3 -m assistant_app --qt
```

Current scope:

- Production calendar shell
- Production calendar selector
- Month navigation
- Calendar visibility toggles
- Selected-day event list
- Existing SQLite data reuse

The preview is intended for resize and navigation validation before more workflows are ported.
